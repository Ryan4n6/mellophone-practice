Honk It Up!

Privacy policy. Last updated 19 August 2026.

This app collects nothing.

No account, no sign-up, no analytics, no advertising, no crash reporting, no tracking. The app makes no network requests of any kind and works exactly the same in airplane mode.

What stays on your device

The app remembers a few things so it is useful the second time you open it:

  • Which instrument you selected.
  • Your practice range, volume and scale speed.
  • Your practice log: the date and length of each session you saved.

All of it is stored on the device itself and nowhere else. It is not sent anywhere, because there is nowhere to send it: this app has no server and no backend. Deleting the app deletes all of it.

Children

This is a practice tool for band students, so the people using it are expected to include minors. That is precisely why the answer to every collection question is none. Nothing personal is requested, entered or gathered, so there is nothing to disclose, sell or lose.

Third parties

There are none. The app bundles no third-party SDKs, frameworks or analytics libraries. Nobody else receives anything, because nothing leaves the device.

The web version

The same tool runs in a browser at ryan4n6.github.io/mellophone-practice. It is a single HTML file that loads no external scripts, styles, fonts or images, and it stores the same handful of settings in your browser's local storage. The page is served by GitHub Pages, whose own server logs are outside our control and are described in GitHub's privacy statement.

Changes

If a future version of the app ever collected anything, this page and the App Store privacy label would be updated in the same release that introduced it. Today both read the same way: data not collected.
